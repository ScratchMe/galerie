# Galerie photo — antoine.berthaud.me

Site statique publié sur GitHub Pages. Remplace Adobe Portfolio.

- `galleries.json` : la liste et l'ordre des galeries.
- `photos/<galerie>/` : les photos (JPEG), dans l'ordre des noms de fichiers.
- Chaque modification sur `main` republie le site (workflow « Publier la galerie »).

Ajouter une galerie : créer un dossier dans `photos/`, y déposer les photos, ajouter une ligne dans `galleries.json`.
